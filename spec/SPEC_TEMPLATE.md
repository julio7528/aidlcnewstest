## Filename and Status

- **Filename:** `p[PP]-St[SS]_[NN]-[short-name]([Status]).md`; replace the period in the roadmap step ID with an underscore.
- **Example:** `p01-St01_06-design-approval(Backlog).md`.
- **Status values:** `Backlog`, `Doing`, `Waiting`, or `Done`; use this exact capitalization in the filename and the Status field below.
- **Backlog:** execution has not started. **Doing:** execution is active. **Waiting:** execution started but is paused for owner input, approval, or an external response. **Done:** acceptance criteria are complete and required owner approval is recorded.
- **Phase-wide specifications:** when one file covers a continuous step range, use the endpoint format defined in `spec/README.md`.
- When the status changes, rename the file and update its links and index entry.
