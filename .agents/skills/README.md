# Project Skills

These skills provide repeatable workflows for the frontend, backend, and QA
agents during execution of user-requested specification steps.

| Skill | Use |
| --- | --- |
| `frontend-spec-implementation` | Implement assigned frontend steps from a selected specification. |
| `backend-news-event-search` | Implement assigned retrieval and filtering steps for news and events. |
| `spec-acceptance-validation` | Validate acceptance criteria for assigned specification steps. |

Each skill has its own directory and `SKILL.md` with its name, description,
ordered workflow, and completion criteria. These workflows follow the user
request, selected specification, and project instructions. Supporting
`scripts/`, `references/`, or `assets/` are added only when required.
